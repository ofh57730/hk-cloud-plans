## 先把問題倒過來問：你的訪客從哪裡來

大部分選錯方案的原因，是拿「頻寬數字」當決策依據。10Mbps 跟 200Mbps 擺在一起，多數人會直接選大的，但如果你的訪客在台灣或新加坡，而機器掛的是純國際線路，那條 200Mbps 反而比一條 10Mbps 的三網直連更適合你。

三種常見線路的分工大致是這樣：

- **三網直連（CN2 + CMI + CUG）**：電信、聯通、移動各自直連回香港機房，不繞第三地。大陸訪客的延遲最低，晚高峰也穩，代價是頻寬單價高，所以這類方案頻寬通常給得保守。
- **BGP 多線／三網混合**：整合多家運營商出口自動擇路，大陸訪問有優化但不是專線級別，頻寬成本比純 CN2 低，適合訪客混合的站點。
- **國際大帶寬（IIJ、亞太混合）**：頻寬大、單價便宜，海外互通好，但對大陸沒有特別優化，回程可能繞日本或走一般國際骨幹。

第三方測評的實測數字可以拿來當參考區間。香港三網直連類方案，全國三網平均延遲大約落在 45～52ms，其中聯通方向表現最好（約 38ms），移動稍高（約 50ms 上下）；換成不優化大陸的國際線路，晚高峰延遲與丟包會明顯拉開。這些是測評者在特定時段的單次結果，不同運營商、不同城市會有波動，但量級差距足以影響選型判斷。

## 流量疊加型 vs 不限流量型：這一步比選區更容易選錯

同樣的 CPU 與記憶體，雨雲給你兩種計費個性：

- **流量疊加型**：每月有一定流量配額，頻寬給得比較大方。當月用不完的流量會結轉到下一期，不會直接歸零。用完之後不是斷網，而是降速（約 5Mbps），需要恢復高速可以加購流量包。
- **不限流量型**：不看流量看頻寬，同配置的頻寬通常明顯低於流量型，換來的是不必盯著流量表過日子。

判斷方式很簡單：網站、落地頁、API 這類「頻寬峰值重要、總量可控」的業務，選流量疊加型，尖峰時段打開速度會好看很多。長時間傳輸、備份、跑中轉或爬蟲調度這類「總量大、對瞬間速度不敏感」的業務，選不限流量型更省心，也不用擔心某天流量超標被降速。

## 常見問題

**香港 3 區的三網直連跟 2 區的三網混合，該選哪個？**
看你的容忍度。3 區線路品質最好但頻寬小，適合企業官網、後台管理、API 這類流量不大的用途；2 區線路略遜但頻寬空間大，訪客量有成長預期時更耐用。兩者的差距不在「誰比較高級」，而在你要用頻寬換線路純度，還是反過來。

**我想放影片或做下載站，是不是該直接上 5 區大帶寬？**
如果你確定了訪客都在海外，5 區的 1Gbps 等級頻寬加 1TB 流量確實更划算。但只要有一部分訪客在大陸，純國際線路在晚高峰的體驗落差會很明顯，這種情況反而要嘛選 2 區加中轉，要嘛老實接受 3 區的小頻寬。

**香港雲端伺服器真的完全不用備案嗎？**
對，香港節點不需要走大陸 ICP 備案，網域綁定後可以直接上線，這也是很多人把展示站、跨境後台放在香港的直接原因。
